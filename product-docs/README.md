# Introduction

Welcome to Meme Theft Auto. We are a Web4 engine that rewards Grand Theft Auto V Online players for the fortunes they already earned, and the builders of Meme City, a browser-based multiplayer sandbox where every street is a doorway and every doorway runs on $MTA. Verification, Meme City, the Marketplace and the token presale are all live. This is not a roadmap. It's a city you can walk into right now.

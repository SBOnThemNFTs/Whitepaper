# Mint Access NFT

In order to fully interact with the verification platform, the registered wallet must have an Access NFT in it. The NFT will be soul bound preventing holders from sending to any other wallet and permanently linking that wallet with the registered GTA Online profile. The NFT is 100% free, but users need to have at least 0.025 SOL (about $5 currently)  in thier wallet to complete a succesful transaction. The transaction fee is about 0.0005 SOL (about $0.10 currently). Once NFT is minted , the user will be able to see and engage with their full profile.&#x20;

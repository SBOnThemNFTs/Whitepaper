# Solana Wallet Creation

We understand with the migration of the GTA Online audiance, many users may not be familair with nor have a Solana based crypto wallet. We want to make things easy as possible for all first timers, so here is a quick, concise guide.



### How to Download and Create a Phantom Wallet (Solana)

#### _Desktop (Browser Extension)_

1\. Go to [phantom.com/download](https://phantom.com/download).

2\. Pick your browser (Chrome, Brave, Firefox, Edge, Opera).

3\. Install the Phantom extension from the official store.

4\. Click the Phantom icon → Create new wallet.

5\. Choose either:

• Seed phrase wallet → Write down your Secret Recovery Phrase safely offline.

• Seedless wallet → Sign in with Google/Apple and set a PIN.

6\. Set a password (for local unlock only).

7\. Done — your wallet is ready.

***

#### _Mobile (App)_

1\. Go to App Store (iOS) or Google Play (Android) via [phantom.com/download](https://phantom.com/download).

2\. Install Phantom (verify the publisher is _Phantom Technologies, Inc._).

3\. Open the app → Create new wallet.

4\. Pick seed phrase or seedless option.

5\. Set PIN/biometrics for access.

6\. Wallet is ready.



{% hint style="info" %}
Security Basics

• Always download via [phantom.com](https://phantom.com/download) — fake apps/extensions exist.

• Back up your recovery phrase offline if using seed phrase.

• Enable auto-lock and device security (PIN/biometric).

• Test with a small SOL transfer first.
{% endhint %}

# How It Works

Our verification process is meticulous to ensure users profiles are not able to be falsely registered, keeping players accounts and $MTA safe. We’ve developed a multi-step validation system that will keep the integrity of this process secure.<br>

1. After joining the project’s discord, users must fill out a registration form including the rockstar profile they intend to claim and Solana wallet address that will be permanently linked to the account.
2. Once accepted, users will visit our verification platform and enter their previously provided rockstar profile name, wallet address, and game system type.&#x20;
3. Users must upload a screen recorded video showing profile name and "Cash Earned (Total Earned)" from thier GTA5 online stats.&#x20;
4. Once submitted, a random crew name will be generated. Participants must join assigned crew through the social club and add crew tag. (_Once verified, keeping the crew tag is not mandatory._)
5. The users request to join the crew will be verified before approval of application. This proves ownership of the profile.
6. Once approved, the user will be redirected to a launchpad where a free access nft can be minted with the linked wallet.&#x20;
7. The verification platform will only allow access to the user hub if NFT is present in the linked wallet for the account. To prevent the transfer of the access nft, each will be frozen indefinitely.&#x20;
8. In the user hub, the user will be able to view the number of accumulated in game-dollars, and  conversion rate to $MTA. Once claim is live, users will also be able to acquire allocated $MTA through their hub account.&#x20;



These steps are to minimize any risk factors for fraudulent or duplicate claims, while providing simplified - _from start to finish_ - steps to participate.
